# Exam Battle 使用手冊

Exam Battle 是不限定科目的考試題庫與多人競賽練習系統。本手冊說明如何安裝、啟動與操作，並會隨每個開發階段更新。

> **目前版本：1.0.0＋題目圖片（第一到第八階段與題目圖片全部完成；發行版號另行決定）**
> 可以使用：帳號、聊天、競賽房間與**多人即時競賽**、題庫管理（單選／多選／是非題，以及閱讀測驗、克漏字等共用文章的**題組**；**公開／私人考卷、考卷搜尋、管理員下架**）、單人練習、練習紀錄與個人成績、錯題本、考卷匯入（PDF／圖片文字擷取與 OCR、切題、題組、校正、答案卷、匯入題庫）。
> 所有規劃的階段都已完成，見[第 13 節](#13-功能進度)。

## 1. 系統需求

| 項目 | 需求 |
|---|---|
| 作業系統 | Windows（客戶端的 JavaFX 原生檔目前只打包 Windows 版） |
| Java | JDK 21 以上（本機為 JDK 25） |
| 建置工具 | Maven 3.9 以上（只有建置時需要） |
| 資料庫 | MariaDB 10.6 以上，只有**伺服器**需要（本機為 MariaDB 13.0） |
| OCR 語言資料 | 繁中＋英文（約 28MB），只有**客戶端**的考卷匯入需要，見 [OCR.md](OCR.md) |

伺服器與客戶端可以在同一台電腦執行，也可以在不同電腦執行，只要客戶端連得到伺服器的埠號（預設 5555）。

## 2. 第一次安裝

### 2.1 使用發行版（1.0.0）

發行版 `exam-battle-1.0.0.zip` 已包含三個程式、資料表結構、OCR 語言資料與文件，不需要 Maven。解壓縮後：

| 檔案 | 用途 |
|---|---|
| `start-server.bat` | 啟動伺服器（預設埠號 5555；需要 MariaDB） |
| `start-client.bat` | 啟動圖形介面客戶端 |
| `server-1.0.0.jar`、`client-1.0.0.jar`、`tools-1.0.0.jar` | 伺服器、客戶端、壓力測試工具 |
| `db\` | `schema.sql`、`seed_subjects.sql`、升級檔 `migrations\` |
| `config\db.properties.example` | 資料庫連線設定範本 |
| `tessdata\` | OCR 語言資料（繁體中文、英文） |
| `docs\` | 本手冊與資料庫、OCR 設定說明 |

1. 安裝 Java 21 以上。只執行客戶端的電腦不需要 MariaDB。
2. 伺服器電腦：依 [DATABASE.md](DATABASE.md) 建立資料庫與帳號，執行 `db\schema.sql`、`db\seed_subjects.sql`；
   把 `config\db.properties.example` 複製成 `config\db.properties` 並填入密碼。從舊版升級時改為執行 `db\migrations\` 中尚未執行的檔案。
3. 雙擊 `start-server.bat`，再雙擊 `start-client.bat`。

### 2.2 從原始碼建置

> 本機已完成以下步驟。換電腦或重建資料庫時才需要再做一次。

1. **設定資料庫**：依 [DATABASE.md](DATABASE.md) 執行，步驟如下。
   - 建立資料庫與專用帳號。
   - 執行 `db/schema.sql`。
   - 執行 `db/seed_subjects.sql`。
   - 建立 `config/db.properties`。
2. **下載 OCR 語言資料**（客戶端匯入考卷時使用）：依 [OCR.md](OCR.md) 把 `chi_tra.traineddata`、`eng.traineddata` 放到專案根目錄的 `tessdata/`。
3. **建置程式**：在專案根目錄執行：

   ```bash
   mvn -q package
   ```

   完成後會產生三個可執行檔：

   | 檔案 | 用途 |
   |---|---|
   | `server/target/server-1.0.0.jar` | 伺服器 |
   | `client/target/client-1.0.0.jar` | 客戶端（圖形介面；也含主控台版） |
   | `tools/target/tools-1.0.0.jar` | 多人連線壓力測試工具 |

> 伺服器執行中時 jar 檔會被鎖住，重新建置前請先關閉伺服器。

## 3. 啟動系統

### 3.1 啟動伺服器

```bash
java -jar server/target/server-1.0.0.jar
```

看到下面這行就表示啟動成功：

```text
Exam Battle 伺服器已啟動，埠號 5555，按 Ctrl+C 結束。
```

- 要改用其他埠號，在指令最後加上埠號，例如 `... server-1.0.0.jar 6000`。
- 若出現「資料庫設定錯誤」，請確認 MariaDB 服務已啟動，並檢查 `config/db.properties`，詳見[常見問題](#14-常見問題)。
- 在伺服器視窗按 **Ctrl+C** 關閉伺服器。所有客戶端會收到通知並回到登入畫面。

### 3.2 啟動客戶端

```bash
java -jar client/target/client-1.0.0.jar
```

- 每執行一次就開一個客戶端視窗。想在同一台電腦模擬多位使用者，就多執行幾次。
- 啟動時主控台可能出現 `Unsupported JavaFX configuration` 與 `sun.misc.Unsafe` 警告，這是 JavaFX 21 在新版 JDK 上的提示，不影響使用。

## 4. 帳號：註冊與登入

登入畫面有四個欄位：

| 欄位 | 說明 |
|---|---|
| 伺服器 | 伺服器的位址。同一台電腦請填 `localhost`，其他電腦請填伺服器的 IP。 |
| 埠號 | 預設 `5555`，與伺服器啟動時相同。 |
| 帳號、密碼 | 登入用的帳號與密碼。 |

### 4.1 註冊

1. 按「**註冊新帳號…**」。
2. 填寫以下欄位：

   | 欄位 | 規則 |
   |---|---|
   | 帳號 | 3–20 個英文字母、數字或底線，不分大小寫（`Alice` 與 `alice` 是同一個帳號） |
   | 顯示名稱 | 1–32 字元，可以用中文，可與他人重複；留空時使用帳號 |
   | 密碼 | 8–64 字元 |
   | 確認密碼 | 必須與密碼相同 |

3. 按「確定」。看到「註冊成功」後，輸入密碼登入。註冊不會自動登入。

### 4.2 登入

輸入帳號與密碼後按「**登入**」或按 Enter。

| 情況 | 系統回應 |
|---|---|
| 帳號或密碼錯誤 | 顯示「帳號或密碼錯誤」（不會透露是哪一項錯） |
| 同一帳號已在其他視窗或電腦登入 | 顯示「此帳號已在其他地方登入」，需先在另一處關閉視窗 |
| 連不到伺服器 | 顯示「無法連線」，請確認伺服器已啟動、位址與埠號正確 |

### 4.3 登出

直接關閉視窗即可。其他人會看到你「離線了」。

> **安全提醒：** 目前連線未加密，請只在信任的網路（例如家中、教室區網）使用。加密連線預計在第八階段加入。

## 5. 大廳

登入後進入主視窗：

- 視窗上方顯示你的名稱與**目前位置**（大廳或房間代碼）。
- 下方有三個分頁：**大廳**、**房間**、**題庫**。

「大廳」分頁的內容：

| 區域 | 功能 |
|---|---|
| 左側「其他在線使用者」 | 目前登入的其他人，有人上線或離線時自動更新 |
| 中間「大廳聊天」 | 與大廳裡的人聊天。輸入訊息後按 Enter 或「送出」，每則最多 1000 字。 |
| 右側「競賽房間」 | 「建立房間」，或輸入房間代碼後按「加入房間」 |

- 大廳聊天只有**不在房間裡**的人看得到；進入房間後就看不到大廳聊天。
- 訊息時間由伺服器決定，所有人看到的順序一致。
- 系統訊息（例如「Bob 上線了」）也會顯示在聊天區。

## 6. 競賽房間

### 6.1 建立房間

在大廳按「**建立房間**」，畫面會自動切到「房間」分頁。

- 系統產生一組 **6 碼房間代碼**，例如 `K7M2XQ`，代碼不含容易混淆的 0、O、1、I。
- 把代碼告訴其他人，他們就能加入。
- 建立者就是**房主**。

### 6.2 加入房間

在大廳的「房間代碼」欄位輸入代碼（大小寫都可以），按「**加入房間**」或 Enter。

| 情況 | 系統回應 |
|---|---|
| 代碼不存在 | 「找不到房間」 |
| 房間已滿（每間最多 50 人） | 「房間已滿」 |
| 你已經在其他房間 | 「你已在房間 XXXXXX 內」，需先離開原房間 |
| 競賽正在進行 | 「正在競賽中，請等這一場結束」 |

### 6.3 房間畫面

| 區域 | 功能 |
|---|---|
| 上方 | 房間代碼、目前人數、「競賽進行中」標示、「離開房間」；房主在競賽中多一個「結束競賽」 |
| 左側「房間玩家」 | 依加入順序列出玩家，標示【房主】與（你）；房主多一個「移出玩家」按鈕 |
| 中間 | 等待時：房主看到競賽設定，其他人看到「等待房主開始競賽」；競賽中：題目、倒數、結果與排行榜 |
| 右側「房間聊天」 | 只有同房玩家看得到，競賽中也可以聊天 |

### 6.4 移出玩家（房主）

競賽開始前，房主在「房間玩家」選取一位玩家，按「**移出玩家**」並確認。被移出的人會回到大廳並看到提示，其他人會看到「被房主移出房間」。
被移出的人仍然可以用代碼再加入。競賽進行中不能移出玩家。

### 6.5 開始競賽（房主）

房主在中間的「競賽設定」選擇：

| 欄位 | 說明 |
|---|---|
| 考卷 | 選一份考卷；或選「（不限考卷，從分類隨機抽題）」 |
| 分類 | 不限考卷時，從這個分類（或全部）隨機抽題 |
| 出題方式 | 「依考卷順序」或「隨機抽題」（不限考卷時只能隨機） |
| 題數 | 1–100 題；依考卷順序時可以勾選「全部題目」 |
| 每題作答時間 | 10、20、30 或 60 秒，每題相同 |

按「**開始競賽**」。只會出現**已設定正確答案**的題目；閱讀測驗、克漏字等題組題會一起顯示文章。
房間內**所有人（包括房主）都是參賽者**。開始後就不能再加入房間。

### 6.6 作答

1. 開始後約 3 秒，所有人同時看到第一題。
2. 上方顯示「第 i / N 題」、已作答人數、倒數秒數與進度條。
3. 選好答案後按「**送出答案**」。**每題只能送一次**，送出後不能修改。
4. **所有人都作答完，或時間到**，就公布這一題的結果。時間到還沒送出的，這一題以 0 分計。

> 倒數只是顯示用，是否超時由伺服器判斷。網路很慢時，就算畫面上還有時間，也可能被判定逾時。

### 6.7 計分與排行榜

| 項目 | 規則 |
|---|---|
| 答對 | 1000 分 |
| 多選題 | 依學測規則部分給分：n 個選項錯 k 個，得 1000 ×（n − 2k）÷ n 分，最低 0 分 |
| 連續答對加成 | 從連續第 2 題起，每題再加 100 分，最多加 500 分（連續第 6 題起都是 +500） |
| 答錯、部分給分、未作答 | 連續答對歸零 |
| 作答速度 | **不影響分數** |

每題結束時會顯示：你的結果（例如「✔ 答對！+1100（連續答對 2 題，加成 +100）」）、正確答案（✔）、解說，以及排行榜（名次、總分、答對題數、連續答對、本題得分）。同分同名次。
5 秒後自動進入下一題。

### 6.8 競賽結束

- 全部題目完成後顯示**最終排行榜**；房主也可以在中途按「**結束競賽**」，已公布的題目照常計分。
- 你沒有全對的題目（含部分給分、未作答）會**加入錯題本**，畫面會顯示加入了幾題。競賽成績**不會**存到「紀錄」分頁。
- 按「**回到房間**」回到等待畫面，房主可以再開一場。

### 6.9 離開與解散

- 按「**離開房間**」回到大廳，其他玩家會看到你離開。競賽中離開後不能再回到這場競賽，你也不會出現在排行榜上；已公布結果的題目中答錯的仍會加入錯題本。
- **房主離開或斷線時，房間會解散**，所有玩家自動回到大廳，房間代碼失效；進行中的競賽也會中止。房主按離開時會先跳出確認。
- 玩家斷線時，同房的人會看到「斷線，已離開房間」。

## 7. 題庫管理

「題庫」分頁分成三欄：

| 欄位 | 內容 |
|---|---|
| 左：分類 | 大分類清單，最上方的「（全部）」顯示所有考卷 |
| 中：考卷 | 所選分類的考卷清單；上方可以搜尋 |
| 右：考卷內容 | 所選考卷的資訊、題目清單、題目預覽 |

### 7.1 權限

每份考卷可以設為**公開**或**私人**：

- **公開**：所有登入者都看得到，可以瀏覽、練習，也能拿來多人競賽。
- **私人**：只有建立者看得到，其他人在清單、搜尋、練習、競賽中都看不到。
- **新增的考卷預設是私人**（包括從「匯入」分頁建立的新考卷）。在「編輯考卷」的「公開範圍」可以隨時切換。
- 升級前就存在的考卷維持公開。

| | 考卷建立者 | 其他登入者（公開考卷） |
|---|---|---|
| 瀏覽考卷與題目 | ✔ | ✔ |
| 看到正確答案與解說 | ✔ | ✘（只會顯示「是否已設定答案」） |
| 修改、刪除考卷與題目 | ✔ | ✘（按鈕停用） |
| 新增分類 | ✔ | ✔ |

不是建立者時，考卷內容上方會顯示「你不是建立者：只能瀏覽，看不到正確答案。」。
隱藏答案是為了之後的練習與競賽能公平作答。

### 7.2 分類

- 系統預先提供 8 個大分類：數學、英文、國文、電腦科學、自然科學、社會科學、證照考試、其他。
- 按「**新增分類**」可以加入新的大分類，例如物理、日文。分類全站共用，名稱不分大小寫且不可重複。
- 目前只有一層分類，細分類（例如數學 > 微積分）會在之後的階段加入。

### 7.3 考卷

| 操作 | 方法 |
|---|---|
| 新增 | 選好分類後按「**新增考卷**」 |
| 編輯 | 選取考卷後按「**編輯考卷**」 |
| 刪除 | 選取考卷後按「**刪除考卷**」。考卷中的題目會一併刪除，無法復原。 |
| 重新整理 | 按「**重新整理**」，看到其他人剛新增的考卷 |

考卷欄位：

| 欄位 | 說明 |
|---|---|
| 考卷名稱 | 必填，最多 200 字，例如「113 學年度第一學期期中考」 |
| 分類 | 必填 |
| 考試年份 | 選填，西元年 1900–2100 |
| 考試類型 | 選填，自由填寫，例如期中考、學測、多益、證照 |

考卷清單會顯示**題數**、**未設答案**（尚未設定正確答案的題目數）與**公開範圍**（公開、私人、已下架）。

| 欄位 | 說明 |
|---|---|
| 公開範圍 | 「私人（只有我看得到）」或「公開」。被管理員下架的考卷不能選公開 |

### 7.4 題目

選取一份自己的考卷後，右側的按鈕可以使用：

| 按鈕 | 功能 |
|---|---|
| 新增題目 | 加在考卷最後 |
| 編輯 | 修改選取的題目（也可以在對話框中更換題型） |
| 刪除 | 刪除選取的題目 |
| 上移／下移 | 調整題目順序 |
| 編輯題組文章 | 修改選取題目所屬題組的文章，**同組的題目一起改變**（只有屬於題組的題目可以使用） |

點選題目後，下方「題目內容」會顯示完整題目與選項；屬於題組的題目會先顯示題組文章。建立者還會看到 ✔ 標示的正確答案與解說。

**題組**：閱讀測驗、克漏字、文意選填、篇章結構等，是多題共用一篇文章。文章只存一份，題目清單以〔題組 11–15〕標示（數字是題目在考卷中的位置）。
題組的建立方式有兩種：從考卷匯入時自動切出（第 11.4 節），或在題目對話框選擇「新題組」。

#### 題目對話框

| 欄位 | 說明 |
|---|---|
| 題組 | 「不屬於題組」、這份考卷中既有的題組，或「新題組（輸入文章）」。文章最多 20,000 字，克漏字的空格可以寫成【11】 |
| 題型 | 單選題、多選題、是非題（填充、簡答、問答題尚未支援） |
| 題目 | 最多 5000 字，可以換行；有題目圖片時可以空白 |
| 題目圖片 | 選填，見下方「題目圖片」 |
| 選項 | 單選題、多選題才有，見下表 |
| 正確答案 | 是非題才有，選「對」、「錯」或「未設定」 |
| 解說 | 選填，最多 5000 字 |

選項的規則：

- 預設 4 個選項，可以按「新增選項」或各選項旁的「刪除」調整，需要 2–10 個。
- 選項內容最多 1000 字；每個選項也可以放一張圖片。選項文字與圖片至少要有一個（例如選項只有一張地圖時，文字可以空白）。
- **單選題**以左側的圓形按鈕標示**唯一**正確答案。
- **多選題**以左側的核取方塊標示，正確答案可以有多個。
- 在單選與多選之間切換時，選項內容與圖片會保留；多選改成單選時，只保留第一個正確答案。

#### 題目圖片

題目、每個選項、題組文章都可以附一張圖片（圖表、地圖、示意圖等）。按圖片欄的按鈕：

| 選項 | 說明 |
|---|---|
| 選擇圖片檔… | 選擇 PNG、JPG、GIF 或 BMP 檔 |
| 從剪貼簿貼上 | 先用截圖工具（例如 Win＋Shift＋S）截圖，再按這一項 |
| 從原始頁面框選… | 只在「匯入」分頁可以使用，見 11.8 節 |
| 移除圖片 | 拿掉這張圖片 |

- 圖片會自動縮小到寬度最多 1600 像素，每張最多 1 MB，不需要自己處理。
- 圖片在按「確定」儲存題目時才上傳。點一下縮圖可以放大檢視。
- 「編輯題組文章」也可以加入、更換或移除文章圖片。題目預覽區會顯示這一題的圖片。

#### 答案未設定

如果還無法確定正確答案（例如考卷沒有附答案），可以**先不設定**，系統不會自行推測答案：

1. 儲存時會詢問「這題尚未設定正確答案，仍要儲存嗎？」。
2. 儲存後，題目清單會標示「**⚠ 答案未設定**」，考卷的「未設答案」數量也會增加。
3. 之後確定答案時，再用「編輯」補上。

> 未設定答案的題目**不會**用於之後的練習與競賽。

#### 輸入錯誤時

對話框會直接提示錯誤，不會送出。常見的錯誤有：

- 題目空白。
- 選擇題少於 2 個選項，或有選項空白。
- 單選題設定了兩個以上的正確答案。

### 7.5 搜尋考卷

在考卷清單上方的搜尋框輸入關鍵字，按 Enter 或「**搜尋**」：

- 比對**考卷名稱、考試類型、年份、建立者**（帳號或顯示名稱），不分大小寫。例如輸入「模擬」「2024」「王老師」。
- 可以和左邊的分類一起使用；勾選「**只看我的**」只列出自己建立的考卷。
- 按「**清除**」回到完整清單。
- 只會找到你看得到的考卷（公開的，以及自己的私人考卷）；不搜尋題目內容。

### 7.6 管理員下架

管理員登入後，畫面上方會顯示【管理員】，考卷清單下方多出「**下架**」「**解除下架**」按鈕：

- **下架**：選取一份公開考卷並確認。考卷改為私人，別人看不到；建立者仍看得到，但不能再公開。
- **解除下架**：選取「已下架」的考卷。解除後仍是私人，由建立者決定是否再公開。
- 管理員不能修改、刪除別人的考卷，也看不到別人考卷的答案。
- 管理員帳號只能由系統管理者用資料庫設定，見 [DATABASE.md](DATABASE.md)。

## 8. 單人練習

在「**練習**」分頁用題庫中的考卷自我練習。**對錯、分數、作答時間都由伺服器判定**；作答過程中客戶端拿不到正確答案。

### 8.1 選擇練習方式

| 練習方式 | 說明 | 要選的項目 |
|---|---|---|
| 完整考卷 | 依考卷順序作答整份考卷 | 考卷 |
| 隨機抽題 | 隨機抽出指定題數 | 考卷；或選「（不限考卷）」改用分類（分類選「（全部）」就從全部題庫抽）、題數 1–100 |
| 錯題複習 | 練習錯題本中的題目，順序隨機 | 分類（選填） |

- 只會出現**已設定正確答案**的題目。考卷下拉選單會顯示每份考卷可練習的題數。
- 所有人都能練習任何考卷，包括別人建立的考卷。

### 8.2 選擇答案公布方式

| 方式 | 適合 | 作答方式 |
|---|---|---|
| **考試模式** | 模擬正式考試 | 可以用「上一題／下一題」或下方題號自由翻題、修改答案，按「交卷」後一次公布成績與答案 |
| **練習模式** | 邊做邊學 | 每題選好後按「送出答案」，立即顯示對錯、正確答案與解說；送出後不能修改，再按「下一題」 |

設定好後按「**開始**」。

### 8.3 作答

- 上方顯示考卷名稱、目前題號（例如「第 2 / 4 題」）與經過時間。經過時間只供參考，正式的作答時間以伺服器紀錄為準。
- **單選題**以圓形按鈕作答；**多選題**以核取方塊作答，可以複選；**是非題**選「對」或「錯」。
- **題組**的題目在上方顯示「題組文章」，可以捲動，也可以按標題收合；收合後換題時維持收合。克漏字的空格【11】以藍色粗體標示，題目會寫「第 11 格」。
- 考試模式下方的題號按鈕中，**淺藍色**是已作答，**深藍色**是目前這一題。
- 交卷時若有未作答的題目，系統會提醒：未作答以 0 分計，並列入錯題。
- 練習模式可以隨時按「**結束練習**」：已送出的題目照常計分，未作答的以 0 分計。

> 同時只能進行一個練習。進行中切換到其他分頁沒有關係，但**關閉視窗或斷線會遺失尚未交卷的練習**。

### 8.4 計分方式

| 題型 | 得分 |
|---|---|
| 單選題、是非題 | 答對 1 分，答錯或未作答 0 分 |
| 多選題（學測規則） | 全對 1 分；有 k 個選項的選擇與正確答案不同（多選或漏選都算），得 (選項數 − 2k) ÷ 選項數，最低 0 分；未作答 0 分 |

多選題 5 個選項時：錯 1 個得 0.6 分、錯 2 個得 0.2 分、錯 3 個以上得 0 分。

- **總分** = 各題得分的平均 × 100（四捨五入到小數一位）。例如 3 題得分 1、0.6、0，總分為 53.3。
- **答對題數**只計算全對的題目；**正確率** = 答對題數 ÷ 題數。

### 8.5 結果

交卷（或練習模式全部作答完）後顯示結果：

- 總分、答對題數、答錯題數、正確率、作答時間。
- 每一題的內容與選項：✔ 為正確答案，● 為你選的選項，選錯的以紅色顯示；並列出你的答案、正確答案、得分與解說。
- 題組的文章顯示在該題組第一題的上方（預設收合，點標題展開）。
- 答錯的題目（含部分給分與未作答）已自動加入錯題本。
- 「**再練一次**」以相同設定重新開始；「**回到設定**」回到設定畫面。

## 9. 練習紀錄與個人成績

「**紀錄**」分頁會保存每一次練習。

- 上方「個人成績」：練習次數、作答題數、答對題數、正確率、平均分數。
- 下方紀錄表格：完成時間、方式、名稱、分數、答對／題數、正確率、作答時間，最新的在最上面。
- **雙擊**一筆紀錄，或選取後按「查看詳細結果」，會開啟該次的完整結果（與 8.5 相同）。
- 紀錄保存的是**作答當時的題目**：考卷或題目之後被修改、刪除，紀錄的內容與正確答案都不會改變。
- 只看得到自己的紀錄。

## 10. 錯題本

「**錯題本**」分頁收集你答錯的題目。

- **加入方式**：交卷時，沒有全對的題目（含多選部分給分、未作答）會自動加入；已在錯題本中的題目，錯誤次數加 1。
- **移除方式**：**只能手動移除**。選取題目後按「移出錯題本」並確認。即使在練習中答對了，題目也會留在錯題本，確定學會後再自行移除。
- 表格顯示題目、分類、所屬考卷、錯誤次數、最近答錯時間；可以用上方的「分類」篩選。
- 選取題目後，下方顯示正確答案（✔）與解說；題組的題目會先顯示題組文章。
- 按「**複習錯題**」會切到「練習」分頁並預先選好「錯題複習」與目前的分類，選擇考試模式或練習模式後按「開始」。
- 題目被建立者刪除時，會自動從錯題本消失。

## 11. 考卷匯入（PDF／圖片辨識）

「**匯入**」分頁可以從考卷的 PDF 或圖片擷取文字，並依題號與選項格式**切成題目**；校正內容、設定答案（手動或匯入答案卷）後，再**匯入題庫**。

> 🔒 **檔案只在你的電腦上處理**：原始 PDF／圖片不會上傳到伺服器，也不會被複製保存。
> 辨識結果在你按「匯入題庫」之前都只是**草稿**；系統**不會推測正確答案**，答案由你設定或從答案卷匯入。

使用 OCR 需要語言資料，本機已下載完成。換電腦時的設定方式請見 [OCR.md](OCR.md)。

### 11.1 擷取文字

1. 按「**選擇檔案…**」，選擇考卷檔案：PDF、JPG、JPEG 或 PNG，單一檔案 50MB 以內，PDF 最多 100 頁。
2. 按「**開始擷取**」。進度列會顯示「第 i / N 頁」；處理中可以按「**取消**」，已完成的頁面會保留。
   - **有文字層的 PDF**（例如由 Word 匯出）：直接讀取文字，幾乎瞬間完成，最準確。
   - **掃描的 PDF、照片、圖片**：自動改用 OCR 辨識，每頁約 3–5 秒。
   - PDF 的文字層是亂碼時，勾選「**強制 OCR**」再擷取一次。
3. 完成後，狀態列會顯示共處理幾頁、其中幾頁使用 OCR。

### 11.2 擷取結果

擷取完成後，切出的題目會列在左側，每題都是待校正的草稿：

- 題型依考卷中的「單選題／多選題／是非題」分段標題推測；有選項但沒有分段標題時推測為單選，無法判斷時需要你選擇。
- 頁首、頁尾、頁碼（例如「第 1 頁」「- 1 -」）與大題標題（例如「一、詞彙題」「說明：…」）會自動略過，不會混進題目或選項。
- 「第 11 至 15 題為題組」之類的標題會切成**題組**，文章自動放進題組（見第 11.4 節）。
- 「混合題」「非選擇題」段落的題目標成〔非選擇題〕並**預設不勾選**，系統目前只支援單選、多選、是非題。
- 正確答案一律為「未設定」，系統不推測答案。
- 擷取時發現的可疑之處會顯示在校正區下方，例如：

| 警示 | 意思 |
|---|---|
| 找不到選項，請確認題型 | 沒有辨識到 (A)(B)… 選項 |
| 只找到 1 個選項 | 選項記號可能沒有辨識出來 |
| 選項字母不連續 | 例如只找到 A、C、D，B 可能漏掉了 |
| 選項記號辨識不完整 | OCR 漏掉括號或把 (C) 讀成 (0，請確認選項切分 |
| 題號不連續 | 中間可能有題目沒有辨識到 |
| 題目內容過短 | 題目可能辨識不完整 |
| 選項可能是圖片或圖表 | 選項是地圖、圖表等圖片，只擷取到零碎文字；請對照原始頁面，把選項改成文字描述 |
| 找不到這一題 | 題組範圍內有題號沒有辨識到，已先產生空白題目，請對照原始頁面補上 |
| 非選擇題…預設不匯入 | 填充、簡答、作文等題目，系統尚未支援 |
| 可能是題組文章，請確認範圍 | 沒有「第 x 至 y 題為題組」標題，但兩題之間有一大段文字；系統暫時把它當成下一題的題組文章 |
| 文章中找不到第 N 格的空格 | 克漏字文章中沒有找到這一格的空格，請在文章中補上【N】 |

### 11.3 校正題目

擷取完成後，畫面分成三欄：

| 區域 | 內容 |
|---|---|
| 左：題目 | 每題前有「匯入」核取方塊與狀態：✔ 可匯入、○ 未設答案、⚠ 需修正、☁ 已匯入 |
| 中：校正 | 編輯選取的題目 |
| 右：對照 | 「原始頁面」顯示該題所在頁面的圖片，「擷取文字」顯示該頁的文字 |

校正區可以修改：

- **題號**：用來對應答案卷。
- **題型**：單選、多選、是非。擷取時無法判斷題型的題目，必須先選擇題型。
- **題目內容、解說**。
- **選項**：可修改文字、刪除、「新增選項」。OCR 常把兩個選項併在一起（例如「15 (pp17」），請把它拆開。
- **正確答案**：單選題點選圓形按鈕，多選題勾選核取方塊，是非題選「對／錯／未設定」。

修改會立即生效。校正區下方會顯示：

- 紅字：需要修正的原因，例如「請選擇題型」「第 2 個選項不可空白」。
- 「尚未設定正確答案」：仍可匯入，但匯入後不會用於練習。
- 橘字：擷取時的提醒，僅供參考。

其他操作：

- 「**新增題目**」：補上沒有辨識到的題目。
- 「**刪除**」：刪除誤判的題目。
- 「**全選**」「**全不選**」：快速勾選或取消要匯入的題目。

> 原始頁面圖片是從你選擇的本機檔案**即時轉出**的，只存在記憶體，不會寫入草稿，也不會上傳。
> 從草稿接續校正時，按「選擇原始檔以對照…」重新選擇原檔即可看到圖片。

### 11.4 題組（閱讀測驗、克漏字、文意選填、篇章結構）

切題時會依「第 11 至 15 題為題組」「請閱讀下文，回答第 1 至 3 題」「Questions 1-3」等標題，把同一篇文章的題目放進同一個**題組**。左側清單以〔題組 11–15〕標示。

| 類型 | 考卷的樣子 | 切題結果 |
|---|---|---|
| 閱讀測驗 | 文章後面每題有題目與選項 | 照常切題，每題共用文章 |
| 克漏字 | 文章中有空格，每格一行「11. (A)… (B)…」 | 題目寫「第 11 格」，文章中的空格標成【11】 |
| 文意選填、篇章結構 | 文章中有空格，最後只有一組共用選項 (A)–(J) | 每格產生一題，題目寫「第 21 格」，選項都是同一組 |

選取題組中的題目時，校正區上方會出現「**題組文章**」：

- 直接修改文章，**同組的題目一起改變**。克漏字的空格請保持【11】的寫法，練習時會以粗體顯示。
- 「**移出題組**」：這一題不再使用這篇文章。
- 「**加入上一題的題組**」：把這一題放進清單中上一題的題組（例如補上漏掉的題目後使用）。
- 「**新增題組…**」：輸入題號範圍並貼上文章，範圍內尚未匯入的題目會放進新的題組（原本屬於其他題組的題目會移過來）。用於沒有被自動辨識的題組。

題組文章空白時，同組的題目會標成 ⚠ 需修正。

> **建議一次匯入整個題組。** 同一題組分兩次匯入時，題庫中會變成兩個題組（文章各存一份）。

### 11.5 匯入答案卷

按「**匯入答案卷…**」：

1. 在文字框貼上答案，或按「從答案卷檔案擷取…」選擇答案卷的 PDF／圖片（同樣只在本機處理）。
   支援的寫法：
   - `1.B 2.AC 3.○ 4.×`（同一行或每行一題）
   - `1 (B)`、`2、A,C`
   - 表格兩行式：`題號 1 2 3` ＋ `答案 B C A`
   - 是非題：`○ O 對 T ✓` 為對、`× X 錯 F` 為錯
   - 大考參考答案的三欄表格（`1 B 21 E 41 A`）也可以直接擷取；`／` 表示非選擇題，會略過；以 `※` 開頭的附註會略過
2. 下方「解析結果預覽」列出每題的答案，以及「⚠ 無法解析」的部分。
   OCR 常把 ○ 讀成 0，這時請直接修改上方文字（例如把「5.0」改成「5.○」）。
3. 按「**套用**」：依題號帶入答案，並顯示結果：
   - 已套用幾題。
   - 哪些題號找不到。
   - 哪些題目沒有套用與原因，例如「單選題卻有多個答案」「題型未選」「答案超出選項數」「切題時判斷為非選擇題」。
   - 答案卷標為「／」的非選擇題題號。

系統只套用能明確對應的答案，不會猜測。套用後仍然可以在校正區修改。

### 11.6 匯入題庫

按「**匯入題庫…**」：

1. 系統先檢查勾選的題目：
   - 有 ⚠ 需修正的題目時，不能匯入，並自動選取第一題需修正的題目。
   - 有未設答案的題目時，會先詢問是否仍要匯入。
2. 選擇匯入目標：
   - **建立新考卷**：填寫考卷名稱（預設為原檔名）、分類、年份、類型。
   - **加到我的考卷最後**：只能選擇自己建立的考卷。
3. 按「**匯入**」。**勾選的題目一次全部匯入**，任何錯誤都會整批取消，題庫不會只多出一部分。
4. 成功後顯示「已匯入 N 題到『考卷名稱』」。這些題目會標示 ☁ 已匯入、取消勾選且不能再修改，避免重複匯入。

匯入後可以到「題庫」分頁查看，或到「練習」分頁開始練習。一次最多匯入 200 題。題組與文章會一起匯入。

### 11.7 儲存與開啟草稿

- 「**儲存草稿…**」把頁面文字與校正內容（含答案、勾選、已匯入標記，以及題目、選項、題組文章的圖片）存成本機檔案（`*.ebdraft.json`），位置由你選擇。草稿只記錄原檔名，不記錄檔案所在的資料夾，也不含原始頁面的圖片。
- 「**開啟草稿…**」重新開啟先前儲存的草稿，不需要再辨識一次，可以接續校正與匯入。草稿也會保存題組與文章；第六、七階段儲存的舊草稿也能開啟。

### 11.8 圖片：自動截圖、框選、自備圖片

**自動截圖**：擷取時，如果某一題的選項看起來是圖片（例如四張地圖、圖表），系統會：

- 清空這一題的選項文字（辨識出來的只是圖中零碎的文字）；
- 依 (A)(B)(C)(D) 記號在原始頁面上的位置，自動截下每個選項的圖片放進選項；
- 顯示警示「選項可能是圖片或圖表…請對照原始頁面確認」。

狀態列會顯示「自動截取 N / M 題的圖片選項」。截圖只是草稿，請對照原始頁面確認範圍。一般文字選項不會被換成圖片。

**框選**：在題目、選項或題組文章的圖片欄選「從原始頁面框選…」，右側會切到「原始頁面」，在頁面上拖曳框出範圍，放開滑鼠就會截下。按 Esc 取消。截圖用高解析度頁面截取，比畫面上看到的清楚。框選需要原始檔；從草稿開啟時請先按「選擇原始檔以對照…」。

**自備圖片**：也可以用「選擇圖片檔…」或「從剪貼簿貼上」（見 7.4 節「題目圖片」）。

- 校正時圖片只在這台電腦上；儲存草稿時圖片也會存進草稿檔。
- 按「匯入題庫」時，系統先逐張上傳圖片（狀態列顯示「上傳圖片 N / M」），再匯入題目。**原始考卷檔案仍然不會上傳**，上傳的只有題目中的圖片。
- 題幹與題組文章的圖片不會自動截取，請用框選或自備圖片。

### 11.9 提高辨識品質

- 優先使用有文字層的 PDF。
- 掃描時使用 200–300 DPI，文件擺正、清晰、沒有陰影或反光。
- 數學公式、表格、圖片、直排文字、手寫的辨識效果不佳，需要在校正時手動修改。

## 12. 其他工具

### 12.1 主控台客戶端（測試用）

主控台版可以註冊、登入、使用房間與聊天，**沒有題庫、練習與匯入功能**。適合除錯，或在沒有圖形介面的環境測試連線。

```bash
java -cp client/target/client-1.0.0.jar com.exambattle.client.ClientMain localhost 5555
```

| 指令 | 功能 |
|---|---|
| `/register <帳號> [顯示名稱]` | 註冊，之後會詢問密碼 |
| `/login <帳號>` | 登入，之後會詢問密碼 |
| `/create` | 建立房間 |
| `/join <代碼>` | 加入房間 |
| `/room` | 顯示房間玩家 |
| `/leave` | 離開房間 |
| 直接輸入文字 | 聊天；要送出以 `/` 開頭的文字時請輸入 `//` |
| `/ping` | 測試與伺服器的往返時間 |
| `/help`、`/quit` | 說明、離開 |

### 12.2 多人連線壓力測試

伺服器啟動後，用下面的指令模擬多人同時連線、進房、聊天，並檢查每個人是否收到完整而且順序一致的訊息：

```bash
java -jar tools/target/tools-1.0.0.jar localhost 5555 50 5 10
```

參數依序為：伺服器、埠號、客戶端數、房間數、每人訊息數。最後顯示「結果：通過」表示正常。

工具會建立 `lt_` 開頭的測試帳號。清除方式見 [TESTING.md](TESTING.md) 第 5 節。

## 14. 常見問題

| 問題 | 原因與處理 |
|---|---|
| 客戶端顯示「無法連線」或 `Connection refused` | 伺服器沒有啟動，或位址、埠號填錯。請先啟動伺服器。 |
| 伺服器顯示「資料庫設定錯誤」 | MariaDB 服務未啟動，或 `config/db.properties` 不存在、密碼錯誤，見 [DATABASE.md](DATABASE.md)。 |
| 伺服器顯示「找不到 xxx 資料表」 | 升級後尚未執行 `db/migrations/` 中的升級檔，見 [DATABASE.md](DATABASE.md) 第 3 節「升級既有資料庫」。 |
| 伺服器顯示「questions 資料表缺少 group_id 欄位」 | 資料庫是題組支援之前建立的，請執行 `db/migrations/001_question_groups.sql`，見 [DATABASE.md](DATABASE.md)。 |
| 房主看不到「開始競賽」 | 確認自己是房主（玩家列表標示【房主】）；只有房主可以開始。 |
| 開始競賽時顯示「沒有已設定答案的題目可以競賽」 | 所選考卷或分類的題目都還沒設定正確答案。 |
| 加入房間時顯示「正在競賽中」 | 等這一場結束後再加入。 |
| 按「送出答案」顯示「作答時間已結束」 | 送出時伺服器已經截止（網路延遲時可能發生），這一題以 0 分計。 |
| 競賽成績在「紀錄」分頁找不到 | 多人競賽不存成練習紀錄，只會把答錯的題目加入錯題本。 |
| 被移出房間 | 房主在競賽開始前移出了你；可以向房主確認後再用代碼加入。 |
| 別人說看不到我的考卷 | 新增的考卷預設是私人，請在「編輯考卷」把公開範圍改成「公開」。 |
| 無法把考卷改成公開，顯示「已被管理員下架」 | 請洽管理員解除下架。 |
| 字太小或太大 | 按 Ctrl＋＋ 或 Ctrl＋－ 調整，Ctrl＋0 還原；設定會記在這台電腦上。 |
| 伺服器顯示「缺少 visibility 欄位」或「缺少 is_admin 欄位」 | 資料庫需要升級，請執行 `db/migrations/002_visibility_admin.sql`，見 [DATABASE.md](DATABASE.md)。 |
| 「此帳號已在其他地方登入」 | 同一帳號只能登入一處，請關閉另一個視窗。對方斷線後會自動釋放。 |
| 「與伺服器的連線中斷」並回到登入畫面 | 伺服器已關閉或網路中斷，重新啟動伺服器後再登入即可。 |
| 看得到題目卻看不到正確答案 | 你不是考卷建立者，這是正常的保護機制。 |
| 編輯、刪除按鈕是灰色的 | 你不是考卷建立者，或沒有選取題目。 |
| 開始練習時顯示「沒有已設定答案的題目可以練習」 | 所選的考卷或分類中，題目都還沒設定正確答案；請建立者先設定答案。 |
| 錯題複習顯示「錯題本中沒有可以複習的題目」 | 錯題本是空的（或所選分類沒有錯題）。 |
| 答對了，錯題本裡的題目還在 | 錯題只能手動移除，請到「錯題本」按「移出錯題本」。 |
| 多選題只錯一個選項卻沒有拿到滿分 | 多選題依學測規則部分給分，只有全對才算答對，見第 8.4 節。 |
| 練習到一半，重新登入後練習不見了 | 尚未交卷的練習在關閉視窗或斷線時會遺失，紀錄只在交卷後保存。 |
| 紀錄裡的題目和現在題庫中的不一樣 | 紀錄保存作答當時的題目；之後建立者修改題目不會影響紀錄。 |
| 匯入時顯示「找不到 OCR 語言資料」 | 請從專案根目錄啟動客戶端，或依 [OCR.md](OCR.md) 設定語言資料位置；有文字層的 PDF 不需要語言資料。 |
| 匯入的辨識結果錯字很多 | 掃描品質不足或內容含公式、表格；請改用有文字層的 PDF 或較清晰的掃描，並在校正時修改。 |
| 匯入結果「找不到題號格式的題目」 | 考卷的題號格式無法辨識（例如沒有 1. 或 (1)），頁面文字仍可複製使用。 |
| 「匯入題庫」按鈕是灰色的 | 沒有勾選任何尚未匯入的題目。 |
| 匯入時說有需要修正的題目 | 勾選的題目中有題型未選或格式錯誤（例如選項空白、單選題有兩個答案），請依紅字修正或取消勾選。 |
| 套用答案卷後有些題目沒有答案 | 題號對不上、題型未選，或答案記號無法辨識（例如 OCR 把 ○ 讀成 0）；請看套用結果的說明，修改文字後重新套用或手動設定。 |
| 閱讀測驗的文章被併進前一題的選項 | 考卷沒有「第 x 至 y 題為題組」之類的標題；請用「新增題組…」貼上文章，並從前一題的選項中刪除文章。 |
| 題組的題目都標 ⚠ 需修正 | 題組文章是空的，請在校正區上方補上文章，或按「移出題組」。 |
| 克漏字練習時看不到粗體空格 | 文章中的空格要寫成【11】（全形括號加題號），可以在「題組文章」或題庫的「編輯題組文章」修改。 |
| 校正時看不到原始頁面 | 從草稿開啟時需要按「選擇原始檔以對照…」重新選擇原檔（圖片不會存進草稿）。 |
| 匯入失敗，題庫沒有任何變化 | 整批匯入失敗時全部不會寫入，請依錯誤訊息（「第 N 題：…」）修正後再匯入。 |
| 伺服器顯示「找不到 images 資料表」或「缺少 image_id 欄位」 | 資料庫需要升級，請執行 `db/migrations/003_images.sql`，見 [DATABASE.md](DATABASE.md)。 |
| 選項是地圖或圖表，卻被切成零碎文字 | 正常情況下會自動截圖；如果沒有，請在該選項的圖片欄用「從原始頁面框選…」截圖，並清空選項文字。 |
| 自動截下的圖片範圍不對 | 在該選項的圖片欄重新「從原始頁面框選…」，或「移除圖片」。 |
| 「從原始頁面框選…」顯示需要原始檔 | 從草稿開啟時，請先按「選擇原始檔以對照…」選擇原檔。 |
| 「從剪貼簿貼上」沒有反應或顯示剪貼簿沒有圖片 | 剪貼簿中要是圖片（截圖），不是圖片檔案或文字。 |
| 題目中顯示「（圖片已不存在）」 | 這張圖片已被移除（例如題目修改後換了圖），紀錄中的舊題目就看不到原圖。 |
| 圖片一直顯示「圖片載入中…」 | 網路較慢或連線中斷；選項仍然可以選擇作答。 |
| `mvn package` 失敗：檔案正由另一個程序使用 | 伺服器或客戶端還在執行，請先關閉。 |
| 主控台客戶端中文變亂碼 | 只會在輸入或輸出被導向檔案時發生，請加上 `-Dstdin.encoding=UTF-8 -Dstdout.encoding=UTF-8`。 |
