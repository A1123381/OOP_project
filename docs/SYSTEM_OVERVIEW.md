## 1. 一句話介紹

Exam Battle 是一套**不限科目**的考試題庫與練習系統：把紙本或 PDF 歷屆考卷轉成數位題庫，再用**單人練習**或**多人即時競賽**準備考試。

核心流程：**匯入考卷 → OCR 辨識 → 人工校正 → 建立題庫 → 單人練習／多人競賽 → 成績統計 → 錯題複習**

## 2. 要解決的問題

- 紙本或 PDF 歷屆考卷不易反覆練習，也不易和同學一起比賽。
- 手動把考卷打成題庫很花時間；OCR 可以加速，但結果一定有錯，需要人工檢查。
- 閱讀測驗、克漏字等多題共用一篇文章的題型，一般題庫不容易處理。

## 3. 六條開發原則（需求明定，不可違反）

| 原則 | 說明 |
|---|---|
| 不用 AI、不接 LLM | 不自動產生題目，也不自動判斷答案 |
| 不推測答案 | 正確答案由使用者手動設定，或從答案卷匯入 |
| 不寫死科目 | 分類與題目全部由使用者建立；系統通用於任何考試 |
| OCR 一定可以校正 | 辨識結果只是草稿，匯入前由人工檢查修改 |
| 伺服器說了算 | 多人競賽的計時、判分、計分、排行榜都在伺服器，避免作弊與不同步 |
| 考卷不上傳 | PDF 與圖片只在使用者電腦上處理，不上傳、不保存 |

## 4. 系統架構

主從式架構（Client／Server）：

```
客戶端（JavaFX＋本機 OCR） ──Java Socket，一行一則 JSON── 伺服器 ──JDBC／DAO── MariaDB
```

| 模組 | 內容 |
|---|---|
| `common` | 通訊協定訊息與共用模型 |
| `server` | Socket 伺服器：帳號、房間、聊天、題庫、練習、競賽（計時與計分） |
| `ocr` | PDF 文字擷取、Tesseract OCR、切題、答案卷解析（在客戶端執行） |
| `client` | JavaFX 圖形介面（主要）；主控台客戶端（測試用） |
| `tools` | 多人連線壓力測試工具 |

**技術選擇**

| 項目 | 技術 |
|---|---|
| 程式語言與建置 | Java 21，Maven 多模組 |
| JSON | Jackson |
| 客戶端介面 | JavaFX 21 |
| 資料庫 | MariaDB（JDBC，經由 DAO 存取；schema 與 MySQL 8 相容） |
| 密碼 | PBKDF2WithHmacSHA256，不存明文 |
| 考卷匯入 | Apache PDFBox 3.0.3；Tess4J 5.13.0（Tesseract 5），語言資料為繁體中文＋英文 |

**通訊協定**

- 每一行是一則 JSON：`{type, requestId, payload}`，單行上限 1,048,576 字元。
- 協定逐階段演進到 v0.9，每次變更都記錄在決策文件。

**資料庫**：10 個資料表。

- 帳號：users
- 題庫：subjects、exams、questions、question_options、exam_questions、question_groups
- 練習：practice_records、answer_records、wrong_questions

舊資料庫用 `db/migrations/` 的升級檔升級。

## 5. 開發過程

依需求分成八個階段，每階段完成後停下驗收才進入下一階段。實際完成順序如下：

| 順序 | 階段 | 內容 | 協定 |
|---|---|---|---|
| 1 | 一、二 | Socket 通訊、多客戶端連線、註冊登入、建立／加入房間、大廳與房間聊天 | v0.3 |
| 2 | 三 | 題庫：分類、考卷、單選／多選／是非題、答案管理；JavaFX 客戶端 | v0.4 |
| 3 | 五 | 單人練習、考試紀錄、個人成績、錯題本 | v0.5 |
| 4 | 六、七 | 考卷匯入（PDF／圖片、OCR、切題）、人工校正、答案卷、整批匯入 | v0.6 |
| 5 | 補充 | 題組：閱讀測驗、克漏字、文意選填、篇章結構 | v0.7 |
| 6 | 四 | 多人即時競賽 | v0.8 |
| 7 | 八 | 公開／私人題庫、管理員下架、考卷搜尋、介面優化 | v0.9 |
| 8 | 發行 | 1.0.0 版打包 | — |

調整順序的原因：

- 第四階段（多人競賽）由使用者決定延後，先完成單人功能。
- 「題組」是用真實的 115 學測英文試卷實測後，發現閱讀測驗與克漏字切不好，才追加的需求。

## 6. 功能重點

### 6.1 帳號、房間、聊天

- 註冊、登入，同一帳號只能在一處登入。
- 建立房間會產生 6 碼房間代碼，不含易混淆的 0、O、1、I；每間最多 50 人。
- 房主離開或斷線時，房間解散。
- 大廳聊天與房間聊天分開。

### 6.2 題庫

- **題型**：單選、多選、是非。填充、簡答尚未支援。
- **分類**：預設 8 個大分類（數學、英文、國文、電腦科學、自然科學、社會科學、證照考試、其他），使用者可以新增。
- **考卷**：名稱、分類、年份、類型；題目可以新增、編輯、刪除、排序。
- **權限**：只有建立者能修改考卷；**正確答案只給建立者**，其他人只看得到「是否已設定答案」，練習與競賽才公平。
- **答案可以先不設定**：未設定答案的題目不會用於練習與競賽。
- **題組**：多題共用一篇文章，文章只存一份；修改後同組題目一起改變。

### 6.3 考卷匯入與 OCR（在客戶端本機執行）

**取得文字**

| 來源 | 做法 |
|---|---|
| 有文字層的 PDF | PDFBox 直接讀取文字，最快、最準確 |
| 掃描 PDF、照片 | 轉成 200 DPI 影像，用 Tesseract 辨識繁體中文與英文 |

**檔案限制**：PDF、JPG、PNG；單檔 50 MB 以內；PDF 最多 100 頁。

**切題原理**：OCR 只負責把頁面變成文字；切題是另一個步驟，只用格式規則比對，不用 AI。

1. **移除頁首頁尾**：
   - 頁碼行，例如 `- 1 -`、`第 1 頁`。
   - 一半以上頁面重複出現的頁首／頁尾行。比對時數字視為相同、不計字詞順序。
2. **大題標題與說明**：例如「一、詞彙題（占 10 分）」「說明：…」。
   - 不併進題目，並用來推測題型。
   - 「混合題」「非選擇題」段落標成不支援。
3. **題號**：`1.`、`1、`、`1)`、`(1)`、`第1題`。
   - 題號必須比前一題大，避免把內文數字當成題號。
4. **選項**：`(A)`～`(J)`、`A.`、`A、`、`A)`，依字母順序接受。
   - OCR 辨識壞的記號（漏括號、(C) 讀成 (0）只在剛好是下一個字母時接受，並加警示。
5. **題組**：認得「第 11 至 15 題為題組」「請閱讀下文，回答第 x 至 y 題」「Questions x-y」。
   - 標題到第一題之間是文章。
   - 題組分三種：
     - 閱讀測驗：照常切題，每題共用文章。
     - 克漏字：題目寫「第 11 格」，文章空格標成【11】。
     - 文意選填、篇章結構：文章後只有一組共用選項，依範圍每格產生一題。
6. **警示**：可疑之處都加上警示，例如題號不連續、找不到選項、選項可能是圖片、文章中找不到空格。

**人工校正**

- 三欄畫面：左邊題目清單，中間校正區，右邊原始頁面圖片（本機即時轉出，只存在記憶體）與擷取文字。
- 可修改題號、題型、題目、選項、正確答案、解說、題組文章。
- 草稿可存成本機檔案，只記原檔名，不含路徑或圖片。

**答案卷**

- 可以貼上文字，或從答案卷 PDF／圖片擷取。支援 `1.B 2.AC 3.○ 4.×`、表格兩行式，以及大考參考答案的三欄表格。
- **只套用能明確對應的答案**：題型未選、單選卻有多個答案、字母超出選項數，一律不套用並說明原因。

**整批匯入**：勾選的題目一次匯入，單一交易，失敗就全部不匯入；一次最多 200 題。可以建立新考卷，或加到自己的考卷最後。

### 6.4 單人練習

| 出題方式 | 說明 |
|---|---|
| 完整考卷 | 依考卷順序作答全部題目 |
| 隨機抽題 | 從考卷、分類或全部題庫抽題（1–100 題，預設 10 題） |
| 錯題複習 | 練習自己錯題本中的題目 |

| 公布方式 | 說明 |
|---|---|
| 考試模式 | 可前後翻題修改，交卷後一次公布答案 |
| 練習模式 | 每題送出後立即公布對錯與解說 |

**計分（伺服器計算）**

- 單選、是非：答對 1 分，否則 0 分。
- **多選依學測規則部分給分**：n 個選項錯 k 個，得 `max(0, (n − 2k) / n)` 分。
- 總分：各題平均 × 100。
- 開始練習時不傳送答案。

**紀錄與錯題本**

- 每次練習都保存紀錄，含作答當時的**題目快照**；題目之後被修改或刪除，紀錄不受影響。
- 個人成績：練習次數、作答題數、答對題數、正確率、平均分數。
- 錯題本：沒有全對的題目（含部分給分、未作答）自動加入，再錯一次就累計次數；**只能手動移除**。

### 6.5 多人即時競賽

**流程**：房主設定 → 同步出題 → 倒數作答 → 公布答案與排行榜 → 下一題 → 最終排行榜

- **房主設定**：
  - 題目來源：選考卷（依序或隨機），或從分類／全部題庫隨機抽題。
  - 題數 1–100。
  - 每題作答時間 10／20／30／60 秒。
- **參賽者**：房間內所有人（包括房主）。開始後不能加入房間，也不能移出玩家。
- **時間軸**：
  - 開始後約 3 秒出第一題，所有人同時收到同一題。
  - 時間到，或所有人都作答，就公布答案與排行榜。
  - 5 秒後自動進入下一題。
- **計分（使用者選擇「答對＋連續答對加成」，不看作答速度）**：
  - 答對得 1000 分；多選依學測規則部分給分（例如得 0.6 就是 600 分）。
  - 連續答對從第 2 題起，每題再加 100 分，最多加 500 分。
  - 答錯、部分給分、未作答，連續答對都會歸零。
  - 同分同名次。
- **伺服器控制**：計時、逾時判斷（截止後 0.5 秒寬限）、判分、計分、排行榜都在伺服器。客戶端的倒數只是顯示。
- **房主權限**：
  - 競賽開始前可以移出玩家，被移出的人可以再加入。
  - 可以中途結束競賽，已公布的題目照常計分。
- **結束後**：每位玩家沒有全對的題目加入錯題本；不寫入練習紀錄（使用者選擇）。
- **實測**（兩個帳號，每題 10 秒，3 題）：

| 玩家 | 第 1 題 | 第 2 題（多選） | 第 3 題（題組） | 總分 |
|---|---|---|---|---|
| 小明 | 答對 1000 | 只選對一個 500 | 答對 1000 | **2500** |
| 王老師 | 答錯 0 | 答對 1000 | 時間到未作答 0 | **1000** |

### 6.6 題庫權限、搜尋、管理員（第八階段）

| 考卷狀態 | 建立者 | 其他使用者 | 管理員 |
|---|---|---|---|
| 公開 | 看得到、可修改 | 瀏覽、練習、競賽 | 可以下架 |
| 私人（**新建預設**） | 看得到、可修改 | 視同不存在 | 看不到 |
| 已下架 | 看得到，不能再公開 | 視同不存在 | 可以解除下架 |

- **私人考卷**：在別人的清單、搜尋、練習、競賽中都視同不存在，請求一律回「找不到考卷」，不透露是否存在。
- **管理員只有下架權**：公開不需要審核；管理員不能修改、刪除別人的考卷，也看不到答案。管理員帳號只能用 SQL 設定。
- **考卷搜尋**：比對考卷名稱、考試類型、年份、建立者，不分大小寫；可搭配分類與「只看我的」；不搜尋題目內容。
- **介面優化**：
  - 共用樣式表。
  - 字級可用 Ctrl＋＋／－／0 調整（11–22px），並記住設定。
  - Ctrl+1～7 切換分頁。
  - 視窗標題顯示登入者，管理員顯示【管理員】。

## 7. 實測：115 學年度學測英文試卷

用大考中心公布的 115 學測英文試卷與參考答案 PDF（有文字層，12 頁）實測。PDF 只在本機使用，不放進版本控制。

**切題結果**

- 50 題全部切出，7 個題組的範圍與文章完整。
- 題目與選項中沒有頁首頁尾或大題標題的殘留。

| 題號 | 類型 | 切題結果 |
|---|---|---|
| 1–10 | 詞彙題 | 一般單選，各 4 個選項 |
| 11–15、16–20 | 克漏字（2 個題組） | 文章空格標成【11】…【20】，題目為「第 N 格」 |
| 21–30 | 文意選填 | 10 題，每題共用 (A)–(J) 十個選項 |
| 31–34 | 篇章結構 | 4 題，每題共用 (A)–(E) 五個句子 |
| 35–46 | 閱讀測驗（3 個題組） | 文章完整、各題選項正確；第 38 題（地圖選項）有警示 |
| 47–50 | 混合題 | 標成非選擇題，預設不匯入 |

**答案卷結果**

- 1–46 題全部正確套用。
- 附註「※1. 對公布之試題…」不會被誤讀成「第 1 題＝對」。
- 47、48、50 的「／」視為非選擇題略過；第 49 題的 ADE 因屬於非選擇題不套用。

**匯入結果**：校正第 38 題的地圖選項後，46 題一次匯入題庫，0 題未設答案。

**改寫前的問題**：

- 文章被併進前一題的選項。
- 文意選填、篇章結構一題都切不出來。
- 頁首頁尾黏進選項。

## 9. 1.0.0 發行版

發行版是 `exam-battle-1.0.0.zip`（約 65 MB），解壓縮後就能使用，不需要另外建置。

| 內容 | 用途 |
|---|---|
| `server-1.0.0.jar`、`client-1.0.0.jar`、`tools-1.0.0.jar` | 伺服器、客戶端、壓力測試工具 |
| `start-server.bat`、`start-client.bat` | 雙擊啟動（伺服器預設埠號 5555） |
| `db\` | 資料表結構、初始分類、升級檔 |
| `config\db.properties.example` | 資料庫連線設定範本（不含密碼） |
| `tessdata\` | OCR 語言資料（繁體中文、英文） |
| `docs\`、`README.txt` | 使用手冊、資料庫與 OCR 設定、快速安裝步驟 |

**三步驟啟動**

1. 安裝 Java 21 與 MariaDB，執行 `db\schema.sql`、`db\seed_subjects.sql`。
2. 把連線設定範本複製成 `config\db.properties`，填入密碼。
3. 雙擊 `start-server.bat`，再雙擊 `start-client.bat`。

只執行客戶端的電腦不需要資料庫。

## 10. 目前限制與之後方向

| 項目 | 目前狀況 |

## 11. 建議的簡報結構（可調整）

## 12. 用語對照

| 用語 | 意思 |
|---|---|
| 考卷 | 一份考試，包含多道題目 |
| 題組 | 多題共用一篇文章（閱讀測驗、克漏字、文意選填、篇章結構） |
| 切題 | 把擷取出的文字切成一題一題的草稿 |
| 校正 | 人工檢查並修改 OCR／切題結果 |
| 答案卷 | 考卷的參考答案，可貼上或從檔案擷取 |
| 錯題本 | 個人答錯的題目清單，只能手動移除 |
| 房主 | 建立競賽房間的人，可開始／結束競賽、移出玩家 |
| 下架 | 管理員把不當的公開考卷改為私人，建立者不能再公開 |
